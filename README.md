# COVID-19_Hospitalization_Predictor-ML

A Python machine learning project implementing a real-world CDC dataset to predict COVID-19 hospitalization outcomes and compare various supervised classification models' performance.



# How to Run

`pip install -r requirements.txt`

1. Create a Python Virtual Environment

`py -m venv .venv`

2. Activate the environemnt

`.\.venv\Scripts\Activate.ps1`

3. Install requirements

`python -m install -r requirements.txt`
